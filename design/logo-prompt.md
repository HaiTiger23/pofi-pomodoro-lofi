# Pofi lofi app logo

Mode: built-in image_gen tool through the imagegen skill.

Original generated asset: `design/artwork/pofi-logo.png`, copied unchanged to `pofi_logo.png` for Electron. The app header uses the resized `public/pofi-logo.png`. PNG sizes, Windows ICO and macOS ICNS are generated by `npm run generate-icons`; `public/favicon.ico` is copied from the Windows ICO. Only resizing and format conversion are applied.

Exact generation prompt:

```text

Create exactly one centered icon: a simple cream ceramic coffee mug wearing chunky over-ear headphones in warm muted tan, with one soft curled steam stroke above. Place the unified mug-and-headphones symbol large inside a deep forest-sage rounded-square tile, with a restrained warm amber highlight. Cozy lofi illustration, clean bold silhouette, smooth softly rounded forms, minimal flat shading, calm cream, sage and walnut palette. Keep the design simple and distinctive with thick shapes and generous contrast; no thin lines, no tiny decoration, no photographic detail. The rounded-square tile nearly fills the square canvas with a small even safety margin. Outside the rounded-square tile is genuinely transparent. No text, no letters, no musical notes, no mockup, no desktop UI, no extra icons, no watermark.
```
